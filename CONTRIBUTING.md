# Contributing

This repo is archived and not taking new features. Fixes to the docs are welcome.

1. Run it: `pip install -r requirements.txt && python3 app.py`, then open http://localhost:5000.
2. There is no test suite. `ecr.py` and `eks.py` need AWS credentials and a cluster, so do not run them casually.
3. Branch from `main`, keep the change small, and open a pull request that says what you ran.
